TRÄNINGSPROGRESS – PWA

Filerna är en färdig mobil webbapp/PWA.

För att använda den på iPhone behöver filerna ligga på en HTTPS-webbserver.
En enkel väg från Windows är GitHub Pages:
1. Skapa ett GitHub-konto.
2. Skapa ett nytt repository.
3. Ladda upp alla filer i denna mapp till repositoryts rot.
4. Slå på Settings > Pages > Deploy from branch > main / root.
5. Öppna den skapade https-adressen i Safari på iPhone.
6. Dela-knappen -> Lägg till på hemskärmen.

Data sparas lokalt i webbläsaren på telefonen. Vill du ha synkning mellan enheter behöver vi lägga till en backend/iCloud-liknande lösning senare.
